# Verificación técnica · Cap. 10 · ¿Cómo funciona un TRANSFORMADOR?

**Regla:** cero información falsa. Si no hay fuente buena, no entra al guion.

**Tipos:**
- **HECHO**: dato con fuente abierta y leída (URL).
- **ANALOGÍA**: comparación para entender; se dice su límite.
- **PENDIENTE**: sin fuente buena o falso tal como estaba; se propone frase corregida.

**Fecha de verificación:** 7 nov 2026.

## C. Analogías

| Analogía | Límite |
|---|---|
| "Las dos bobinas se hablan por el campo magnético, sin tocarse" | Bien para T1. No aplica a autotransformadores (un solo devanado compartido). |
| "El núcleo de hierro es como una autopista para el campo magnético" | El núcleo guía el flujo magnético; no transporta corriente eléctrica de una bobina a otra. |
| "Más vueltas = más voltaje, pero menos corriente; como cambiar la marcha de una bicicleta" | La potencia se conserva solo aproximadamente (≈99 % en grandes). No sirve para explicar por qué con DC no funciona. |
| "Qi es un transformador con aire en el medio" | El acople es mucho menor (WPC: coeficiente ≤ 0,5), por eso el celular debe quedar bien centrado y se pierde más energía. |
| "El zumbido es el hierro estirándose y encogiéndose" | Es una deformación microscópica; no hay piezas que se muevan a simple vista. También hay ruido de los devanados y ventiladores. |
